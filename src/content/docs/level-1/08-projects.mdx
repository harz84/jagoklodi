## Tujuan

Setelah pelajaran ini, Anda bisa:

1. Menjelaskan kapan sebaiknya memakai Project dibanding percakapan biasa.
2. Membuat Project dengan project knowledge dan project instructions.
3. Menulis project instructions yang membuat jawaban konsisten.

## Kenapa butuh Projects

Ingat Pelajaran 1: setiap percakapan baru dimulai dari awal. Kalau Anda sering mengerjakan hal yang sama, misalnya laporan bulanan atau administrasi organisasi, Anda harus menjelaskan konteks dan menempelkan dokumen yang sama berulang kali.

**Projects** adalah ruang kerja dengan riwayat percakapan dan kumpulan pengetahuannya sendiri. Ada dua bagian penting:

| Bagian | Isinya | Contoh |
| --- | --- | --- |
| **Project knowledge** | Dokumen dan teks rujukan yang dipakai Claude di semua percakapan dalam Project itu | Template laporan, panduan gaya tulisan, daftar istilah |
| **Project instructions** | Aturan tetap tentang cara Claude menjawab | "Selalu gunakan bahasa formal; laporan maksimal 1 halaman" |

<Aside type="note" title="Yang perlu diketahui">
- Paket Free bisa membuat **maksimal 5 Project**. Paket berbayar mendapat kapasitas pengetahuan yang lebih besar.
- Nama dan deskripsi Project **tidak** dibaca oleh Claude. Konteks harus ditaruh di knowledge atau instructions.
- Isi satu percakapan **tidak** otomatis diketahui percakapan lain dalam Project yang sama, kecuali Anda menambahkannya ke project knowledge.
</Aside>

## Kapan memakai Project

- **Pakai Project** untuk pekerjaan berulang dengan konteks yang sama: laporan rutin, administrasi organisasi, atau materi kursus.
- **Pakai percakapan biasa** untuk pertanyaan sekali jalan.

## Langkah praktik

<Steps>

1. Buka menu **Projects** di sisi kiri (atau buka claude.ai/projects), lalu klik **+ New Project**.

2. Beri nama, misalnya "Laporan bulanan". Ingat, nama ini hanya untuk Anda, bukan untuk Claude.

3. Di area project knowledge di sisi kanan, klik **+** lalu tambahkan satu dokumen rujukan, misalnya contoh laporan bulan lalu yang sudah disamarkan atau template laporan.

4. Klik **Set project instructions**, lalu tulis instruksi tetap. Contoh (fiktif):

    ```text
    Saya koordinator administrasi di sebuah koperasi.
    Di Project ini saya menyusun laporan bulanan untuk rapat pengurus.

    Aturan:
    - Ikuti struktur template di project knowledge.
    - Bahasa formal tapi mudah dipahami pengurus yang bukan orang keuangan.
    - Setiap angka disertai perbandingan dengan bulan sebelumnya.
    - Jika data yang saya berikan kurang, tanyakan dulu; jangan mengarang angka.
    ```

    Lalu klik **Save instructions**.

5. Mulai percakapan di dalam Project dengan prompt singkat, misalnya "Ini data bulan Oktober: …". Perhatikan bahwa Anda tidak perlu menjelaskan ulang konteksnya.

</Steps>

## Contoh nyata

Tanpa Project, setiap bulan Anda menulis prompt panjang berisi konteks, aturan, dan template. Dengan Project, prompt bulanan Anda cukup seperti ini:

```text
Data Oktober (fiktif):
- Anggota baru: 12 (September: 8)
- Simpanan terkumpul: 48 juta (September: 45 juta)
- Pinjaman macet: 2 (September: 3)

Susun laporannya.
```

Konteks, template, dan aturan gaya sudah tersimpan di Project, jadi hasilnya konsisten dari bulan ke bulan.

## Latihan

Buat satu Project untuk pekerjaan berulang Anda sendiri, lengkap dengan minimal satu dokumen di project knowledge dan project instructions berisi minimal tiga aturan.

**Kriteria berhasil:** prompt pertama di Project itu tidak perlu menjelaskan konteks; hasilnya mengikuti aturan di instructions; dan Project tidak memuat data golongan merah.

## Kesalahan umum

- **Menaruh konteks di nama atau deskripsi Project.** Claude tidak membacanya.
- **Mengira percakapan dalam Project saling berbagi isi.** Yang dibagikan hanya project knowledge dan instructions.
- **Instructions terlalu umum**, seperti "jawab dengan baik". Tulis aturan yang bisa dicek, misalnya panjang, struktur, dan nada.
- **Mengunggah dokumen rahasia ke project knowledge.** Aturan lampu lalu lintas data tetap berlaku.
- **Membuat Project untuk setiap pertanyaan kecil.** Project berguna untuk pekerjaan berulang, bukan pertanyaan sekali jalan.
