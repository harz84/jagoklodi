## Tujuan

Setelah pelajaran ini, Anda bisa:

1. Membedakan **memory** dan **pencarian percakapan lama**.
2. Melihat, mengoreksi, dan menghapus apa yang diingat Claude.
3. Memilih kapan memakai percakapan biasa, memory dimatikan, atau incognito.

## Dua cara Claude memakai konteks lama

Di Pelajaran 1 Anda belajar bahwa setiap percakapan dimulai dari awal. Dua fitur ini mengubahnya:

| | **Memory** | **Pencarian percakapan lama** |
| --- | --- | --- |
| Cara kerja | Claude menyimpan hal penting tentang Anda sebagai **topik** selama Anda bercakap | Claude mencari di riwayat percakapan saat Anda memintanya |
| Contoh | Peran Anda, proyek yang sedang berjalan, gaya tulisan yang Anda suka | "Kita pernah bahas anggaran kegiatan, apa keputusannya?" |
| Paket | Semua paket. Aktif secara bawaan di Free, Pro, dan Max | Paket berbayar (Pro, Max, Team, Enterprise) |

Di paket **Team dan Enterprise**, owner organisasi menentukan apakah memory tersedia, dan memory tetap mati sampai setiap anggota menyalakannya sendiri.

## Apa yang diingat dan tidak

Claude mengingat konteks sehari-hari yang membantu pekerjaan, misalnya peran dan proyek Anda, orang yang sering Anda sebut, serta preferensi gaya komunikasi.

<Aside type="caution" title="Batas yang perlu diketahui">
- Secara bawaan, Claude **tidak** menyimpan topik sensitif seperti kesehatan, agama, ras, etnis, atau politik, kecuali Anda menyalakan **Include sensitive topics in memory**.
- Beberapa data **tidak pernah** disimpan meski Anda memintanya, misalnya nomor identitas resmi, nomor rekening, catatan kriminal, dan status imigrasi.
- **Menghapus percakapan tidak menghapus memory** yang sudah tercatat dari percakapan itu. Hapus topiknya secara terpisah di pengaturan memory.
</Aside>

Aturan data merah dari Pelajaran 3 tetap berlaku: jangan mengandalkan penyaring otomatis. Data yang tidak boleh diunggah tetap tidak boleh diketik.

## Tiga pilihan saat memulai percakapan

| Pilihan | Memakai memory? | Menambah memory? | Masuk riwayat? |
| --- | --- | --- | --- |
| **Percakapan biasa** | Ya | Ya | Ya |
| **Memory dimatikan untuk satu percakapan** (**+ → Memory** sebelum pesan pertama) | Tidak | Tidak | Ya |
| **Incognito** (ikon hantu di kanan atas, di luar Project) | Tidak | Tidak | Tidak, tetapi tetap disimpan sementara (bawaan 30 hari) demi keamanan |

Pilihan memory untuk satu percakapan harus diatur **sebelum** pesan pertama terkirim; setelah itu tidak bisa diubah.

## Memory di dalam Project

Setiap Project punya memory sendiri. Di dalam Project, Claude memakai memory Project itu ditambah memory akun Anda, tetapi tidak memakai memory dari Project lain. Bila Project berisi pekerjaan yang harus benar-benar terpisah, matikan **Use account memory** di bagian **Memory** pada halaman Project.

## Langkah praktik

<Steps>

1. Buka **Settings > Your Claude**, lalu klik **Manage** di samping **Your memory**. Di tata letak lama, buka **Settings > Memory**.

2. Baca daftar **Topics**. Cari satu hal yang keliru atau sudah tidak berlaku, misalnya jabatan lama atau proyek yang sudah selesai.

3. Buka topik itu, lalu perbaiki dengan ikon edit atau hapus dengan **Delete**.

4. Di percakapan baru, minta Claude mengingat satu preferensi kerja:

    ```text
    Tolong ingat: untuk semua draf surat organisasi,
    saya memakai salam pembuka "Assalamu'alaikum warahmatullahi
    wabarakatuh" dan penutup dengan nama serta jabatan saya
    sebagai sekretaris.
    ```

5. Buka percakapan baru lagi dan minta draf surat undangan singkat **tanpa** menyebut salam dan penutup. Periksa apakah Claude memakainya sendiri.

6. Mulai satu percakapan dengan memory dimatikan (**+ → Memory**, sebelum pesan pertama) dan ulangi permintaan yang sama. Bandingkan hasilnya.

</Steps>

## Contoh nyata

Tanpa memory, setiap kali menyusun notulen rapat RT, Anda menjelaskan ulang bahwa Anda sekretaris RT 05, notulen selalu dibuka dengan daftar hadir, dan keputusan ditulis bernomor. Dengan memory, cukup tulis:

```text
Ini catatan rapat tadi malam, tolong rapikan jadi notulen.
[tempel catatan]
```

Bila hasilnya memakai format lama yang sudah Anda ganti, koreksi lewat percakapan ("mulai sekarang keputusan ditulis dalam tabel") atau perbaiki topiknya di pengaturan memory.

## Latihan

Periksa memory Anda, perbaiki minimal satu topik, dan tambahkan satu preferensi kerja yang berguna untuk pekerjaan rutin Anda.

**Kriteria berhasil:** minimal satu topik sudah dikoreksi atau dihapus; preferensi baru terbukti dipakai di percakapan baru tanpa Anda sebutkan; dan tidak ada data golongan merah di daftar memory Anda.

## Kesalahan umum

- **Mengira menghapus percakapan juga menghapus memory.** Topik yang sudah tercatat harus dihapus terpisah.
- **Mengandalkan memory untuk aturan yang harus selalu dipatuhi.** Untuk aturan tetap di satu jenis pekerjaan, pakai project instructions (Pelajaran 8); memory lebih cocok untuk konteks umum.
- **Lupa incognito untuk hal sekali jalan yang tidak ingin diingat**, misalnya mencoba prompt untuk keperluan orang lain.
- **Tidak pernah memeriksa daftar memory.** Info usang membuat jawaban melenceng tanpa Anda sadari.
