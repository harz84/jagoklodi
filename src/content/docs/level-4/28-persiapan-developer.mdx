## Tujuan

Setelah pelajaran ini, Anda bisa:

1. Memasang Node.js dan memeriksa versinya.
2. Membuat akun Claude Console dan API key.
3. Menyimpan API key di file `.env` yang tidak ikut ter-commit dan tidak bisa dibaca Claude Code.

## Dari Claude Code ke Claude API

Di Level 3, Claude Code bekerja untuk Anda dengan kuota langganan Claude. Di Level 4, Anda menulis **program sendiri** yang memanggil Claude. Program berkomunikasi dengan Claude lewat **API** (application programming interface), yaitu pintu masuk khusus untuk program, bukan untuk manusia.

Ada tiga hal baru yang dibutuhkan:

| Kebutuhan | Fungsinya |
| --- | --- |
| **Node.js** | Menjalankan program JavaScript di komputer Anda, di luar browser. Semua contoh Level 4 memakai JavaScript |
| **Akun Claude Console** | Tempat membuat API key, membeli kredit, dan melihat pemakaian. Terpisah dari akun langganan Claude |
| **API key** | Kata sandi panjang yang dibawa program setiap kali memanggil Claude. Siapa pun yang memegang key ini bisa memakai saldo Anda |

### Biaya API terpisah dari langganan

Pemakaian API **ditagih terpisah** dari paket Claude Anda. Paket Pro tidak termasuk kredit API, sedangkan paket Max, Ultra, dan Team mendapat kredit API bulanan yang harus diklaim dengan menautkan organisasi Console ke paket. Di luar itu, kredit dibeli lebih dulu (prabayar) di halaman **Billing** Console. Harga per model ada di [halaman harga](https://platform.claude.com/docs/en/about-claude/pricing).

Latihan Level 4 memakai **Claude Haiku 5.5**, model termurah saat ini, dengan batas jawaban kecil. Perkiraan biaya setiap pelajaran dicantumkan di bagian Latihan.

<Aside type="caution" title="Jangan pasang ANTHROPIC_API_KEY untuk seluruh komputer">
Bila variabel `ANTHROPIC_API_KEY` terpasang di terminal Anda, Claude Code memakai key itu dan **tagihannya ikut tarif API**, bukan kuota langganan. Karena itu, jangan menaruh key di file pengaturan terminal seperti `~/.zshrc` atau di variabel lingkungan Windows. Simpan hanya di file `.env` milik proyek, seperti di langkah berikut.
</Aside>

## Langkah

<Steps>

1. **Pasang Node.js.** Buka [nodejs.org/en/download](https://nodejs.org/en/download), pilih versi **LTS** (long-term support, versi yang didukung paling lama), lalu jalankan pemasangnya dengan pilihan bawaan. Contoh Level 4 membutuhkan minimal Node.js 20, dan versi LTS terbaru sudah memenuhinya.

2. **Periksa pemasangan.** Tutup terminal, buka lagi, lalu ketik:

    ```bash
    node --version
    npm --version
    ```

    Hasilnya dua nomor versi, misalnya `v24.x.x`. **npm** adalah pengelola paket yang ikut terpasang bersama Node.js; Anda memakainya untuk memasang SDK.

3. **Buat akun Console.** Buka [platform.claude.com](https://platform.claude.com) dan daftar. Akun ini terpisah dari akun langganan Claude, walau boleh memakai email yang sama.

4. **Siapkan kredit.** Pelanggan Max, Ultra, atau Team: tautkan organisasi Console ke paket Anda lewat **Settings > Billing** di claude.ai, bagian **API credits**. Pengguna lain: buka halaman **Billing** di Console, lalu **Buy credits**. Beli secukupnya untuk latihan, dan biarkan **auto-reload** mati agar pengeluaran tidak melewati saldo yang Anda beli.

5. **Buat API key.** Buka halaman **API keys** di Console ([platform.claude.com/settings/keys](https://platform.claude.com/settings/keys)), lalu buat key baru. Beri nama yang jelas, misalnya `latihan-jagoklodi`, dan pilih masa berlaku. Key hanya ditampilkan **sekali**; salin sekarang.

6. **Buat folder proyek** dan siapkan git:

    ```bash
    mkdir latihan-api
    cd latihan-api
    npm init -y
    npm pkg set type=module
    git init
    ```

    `npm init -y` membuat file `package.json` yang mencatat paket proyek. `type=module` membuat Node.js memakai gaya `import` modern, sama seperti contoh di dokumentasi.

7. **Lindungi file rahasia sebelum membuatnya.** Buat file `.gitignore` berisi dua baris berikut, supaya git mengabaikan folder paket dan file `.env`:

    ```text
    node_modules/
    .env
    ```

8. **Simpan key di `.env`.** Buat file `.env` di folder yang sama, isinya satu baris (ganti dengan key Anda):

    ```text
    ANTHROPIC_API_KEY=sk-ant-...
    ```

9. **Cegah Claude Code membaca `.env`.** Buat folder `.claude` dan file `.claude/settings.json` berisi:

    ```json
    {
      "permissions": {
        "deny": ["Read(./.env)", "Read(./.env.*)"]
      }
    }
    ```

    Aturan `deny` ini berlaku di semua mode izin, sehingga key Anda tidak ikut terbaca dan tersimpan di riwayat sesi Claude Code bila Anda memakai Claude Code di folder ini.

10. **Periksa sebelum commit.** Jalankan `git status`. File `.env` **tidak boleh** muncul di daftar. Bila muncul, periksa lagi isi `.gitignore` sebelum melanjutkan.

</Steps>

## Cara program membaca key

Mulai Pelajaran 29, program dijalankan dengan perintah seperti ini:

```bash
node --env-file=.env halo.js
```

Opsi `--env-file` membuat Node.js membaca `.env` dan menyediakan isinya sebagai variabel lingkungan **hanya untuk program itu**. Terminal Anda dan Claude Code tidak ikut menerima key, sehingga tagihan langganan dan tagihan API tidak tercampur.

## Contoh nyata

Bu Sari (fiktif) ingin membuat program kecil yang menulis deskripsi produk untuk Toko Kue Bu Sari. Ia berlangganan Pro, jadi ia membeli kredit API secukupnya di Console dan mematikan auto-reload. Key disimpan di `.env`, dan `git status` memastikan file itu tidak ikut ter-commit. Saat repository-nya kelak dipublikasikan di GitHub, tidak ada rahasia yang ikut terbuka.

## Latihan

Siapkan folder `latihan-api` sesuai langkah di atas, lalu buat commit pertama berisi `package.json`, `.gitignore`, dan `.claude/settings.json`.

**Kriteria berhasil:** `node --version` menampilkan versi 20 atau lebih baru; API key sudah dibuat dan tersimpan di `.env`; `git status` tidak pernah menampilkan `.env`; commit pertama tidak memuat key; dan `ANTHROPIC_API_KEY` tidak terpasang di pengaturan terminal Anda.

**Perkiraan biaya:** nol. Pelajaran ini belum memanggil API.

## Kesalahan umum

- **Menaruh key di pengaturan terminal** (`~/.zshrc`, `~/.bashrc`, atau variabel lingkungan Windows). Claude Code ikut memakainya, sehingga pemakaian Claude Code ditagih dengan tarif API.
- **Membuat `.env` sebelum `.gitignore`**, lalu tidak sengaja ikut ter-commit. Key yang pernah masuk ke repository publik harus dianggap bocor: hapus key itu di Console dan buat yang baru.
- **Menempel key di prompt atau chat**, termasuk ke Claude. Key cukup ada di `.env`.
- **Mengira kredit Max atau Ultra langsung aktif.** Kredit bulanan harus diklaim dengan menautkan organisasi Console ke paket lebih dulu.
